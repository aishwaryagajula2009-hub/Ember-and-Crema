# ☕ Ember & Crema — Artisanal Café Website

A modern, warm, and responsive single-page website for **Ember & Crema**, an artisanal coffee house and bakery. Built with clean HTML5, custom CSS, and vanilla JavaScript—no external frameworks or build steps required.

## ✨ Key Features

* **Responsive Navigation & Mobile Drawer:** Sticky glassmorphic header with smooth anchor scrolling and an accessible mobile slide-out menu.
* **Welcome Hero Section:** Warm espresso-and-cream editorial aesthetic introducing the café's story, roast philosophy, and quick-action buttons.
* **Barista & Baker Specials:** High-contrast dark showcase highlighting signature drinks and pastries with interactive quick-view tasting notes.
* **Interactive Seasonal Menu:** Category filtering (Coffee, Signature Drinks, Pastries & Brunch), dietary indicators (`V` Vegan, `GF` Gluten-Free), and a persistent **Saved Favorites** tray.
* **Customer Reviews:** Curated guest testimonials and star ratings highlighting the café atmosphere and signature items.
* **Live Opening Hours & Location:** Dynamic current-day highlighting in the weekly schedule alongside address details and a stylized neighborhood map view.
* **Newsletter Signup Footer:** Interactive email subscription form with instant feedback.

---

## 🛠️ Tech Stack

* **HTML5** — Semantic structure and accessible markup
* **CSS3** — Custom properties (CSS variables), Flexbox, CSS Grid, and responsive media queries
* **JavaScript (ES6+)** — Menu filtering, favorites state management, modal/drawer interactions, and dynamic day highlighting
